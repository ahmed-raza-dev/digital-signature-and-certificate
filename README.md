# Digital Signature and Digital Certificate

## Project Overview

This project demonstrates Digital Signatures and Digital Certificates using Python, OpenSSL, and Linux (Ubuntu).

It explains how cryptographic techniques help ensure data integrity, authenticity, and secure document verification.

## Technologies Used

- Python
- OpenSSL
- Linux (Ubuntu)
- Public Key Cryptography
- Digital Certificates

## Project Features

- Public and Private Key Generation
- Digital Signature Creation
- Digital Signature Verification
- Digital Certificate Generation
- Document Integrity Verification
- Tampering Detection

## Project Structure

    digital-signature-project/
    |-- app.py
    |-- documents/
    |-- signature/
    |-- keys/
    |-- certification/
    |-- README.md

## How It Works

1. Generate a public-private key pair.
2. Use the private key to create a digital signature.
3. Verify the signature using the public key.
4. Use a digital certificate to associate a public key with an identity.
5. Detect document modifications through signature verification.

## Security Note

Private keys and sensitive backup files must never be uploaded to a public repository.

## Project Purpose

This project was developed for academic learning to understand digital signatures, digital certificates, and cryptographic verification.
